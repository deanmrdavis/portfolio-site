# dean-davis.com

Source for [dean-davis.com](https://dean-davis.com), the portfolio of Dean Davis, product manager.

- **Stack:** Next.js (static export), TypeScript, Tailwind CSS
- **Hosting:** Netlify, with Netlify Forms for the contact form
- **Content:** all copy lives in `src/content/` as typed data, separate from layout

## Run locally

```bash
npm install
npm run dev
```

Then open http://localhost:3000.
